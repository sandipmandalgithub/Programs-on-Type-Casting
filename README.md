# Java Type Casting Programs

This repository contains Java programs demonstrating **Type Casting** in Java, including both **Primitive** and **Non-Primitive Type Casting**.

These programs were created for practicing and understanding type conversion and type casting concepts in Java.

## 📚 Concepts Covered

### Primitive Type Casting

* Widening Type Casting
* Narrowing Type Casting
* Conversion between primitive data types
* Explicit and implicit type conversion

### Non-Primitive Type Casting

* Upcasting
* Downcasting
* Type casting between parent and child classes
* Inheritance-based type casting

## 🛠️ Technologies Used

* **Programming Language:** Java
* **IDE:** Eclipse IDE

## 🚀 How to Run

1. Clone or download this repository.
2. Open the Java source files in Eclipse IDE or another Java IDE.
3. Open the desired Java class.
4. Run the program as a Java Application.

## 🎯 Purpose

This repository was created for Java programming practice and to strengthen my understanding of **Primitive and Non-Primitive Type Casting** in Java and Object-Oriented Programming.
